# IO-Darts-Agent - Features

## Overview

IO-Darts-Agent is a middleware solution that mediates between the Autodarts platform and various action modules. The hub receives real-time events from Autodarts and forwards them to configured modules.

## Core Features

### 1. Autodarts Integration

#### Authentication
- OAuth2-based login with Autodarts (Keycloak)
- Automatic token management and renewal
- Secure storage of credentials

#### WebSocket Connection
- Persistent WebSocket connection to Autodarts server
- Automatic reconnection on connection loss
- Heartbeat monitoring for connection stability

#### Event Processing

**Native Events** (from Autodarts):

| Event | Description | Data |
|-------|-------------|------|
| `match.start` | New match started | Match ID, board ID |
| `match.state` | Match state update | Players, scores, settings |
| `match.finished` | Match finished | Winner, final scores |
| `match.delete` | Match cancelled | Match ID |
| `throw.detected` | Throw detected | Segment, points, multiplier |
| `game.finished` | Leg/Set won | Winner |
| `takeout.started` | Dart removal started | - |
| `takeout.finished` | Dart removal finished | - |

**Synthetic Events** (generated by EventParser):

| Event | Description | Trigger |
|-------|-------------|---------|
| `player.change` | Player changed | Player index changes in match.state |
| `turn.finished` | Turn finished | 3 darts thrown, bust, or round change |

### 2. Modular Plugin System

#### Module Architecture
- Each module is a standalone package
- Modules define their configuration via `module.json`
- Support for custom web UIs per module
- Modules can be installed from Git repositories
- Multi-language support (EN, DE, ES)

#### Module Lifecycle
```
Installation → Configuration → Start → Running → Stop → Uninstallation
```

#### Event Handling
- Modules register for specific events
- Parallel event processing for multiple modules
- Errors in one module don't affect others

### 3. Web Interface

#### Setup Wizard
- Guided initial setup
- Autodarts connection test
- Board selection

#### Dashboard
- Connection status
- Active modules
- Live event feed

#### Module Management
- View installed modules
- Start/stop modules
- Edit module configuration
- Install new modules (local or Git)

#### Player Management
- Create player profiles
- Individual colors per player
- Aliases for player name matching

#### Live Logs
- Real-time event log
- Filtering by event type
- Module-specific logs

#### Multi-Language
- English (en)
- German (de)
- Spanish (es)

### 4. Player Management

#### Player Profiles
- Name and aliases
- Individual color (for WLED, display, etc.)
- Automatic matching during Autodarts games

#### Color System
- RGB color selection
- Colors are passed to modules
- Fallback colors for unknown players

### 5. Configuration System

#### Hierarchical Configuration
```
Hub Config (hub.config.json)
├── Autodarts Credentials
├── Server Settings
└── Setup Status

Module Configs (config/modules/*.json)
├── wled.json
├── game-display.json
├── darts-caller.json
└── ...
```

#### Live Reload
- Configuration changes take effect immediately
- No server restart needed

## Built-in Modules

### WLED Lighting Controller

Controls WLED-compatible LED controllers based on game events.

**Features:**
- Various action types (Preset, Effect, Solid, Brightness, Off)
- Event-based configuration
- Player color integration
- Temporary effects with automatic restore to player color
- Multi-color effects (up to 3 colors)
- Fade time (transition time) for smooth color changes
- Single-player mode support

**Supported Events:**
- Match start/end
- Player change
- Throws (Triple, Double, Bullseye, Miss, 180)
- Bust
- Takeout finished

**New Features:**
- **Duration with player color restore**: After a temporary effect, the player's color is restored (not the previous WLED state)
- **Fade Time**: Global and per-action transition time in milliseconds
- **Single-player support**: Player color is applied after match start and takeout in single-player games

### Game Display Module

Shows the current game score on a separate display in real-time.

**Features:**
- Large, readable score display
- Checkout suggestions (2-170 points)
- Animated player colors as background
- Throw display (Dart 1, 2, 3)
- Other players bar
- Responsive design for various screen sizes
- Demo mode for testing
- Configurable animations per event
- Idle mode options (waiting screen, last game, black screen, custom image)
- Multi-language support

**Match Start Handling:**
- Automatically fetches full match data via API when match starts
- Prevents showing default values (501, "Player") at game start

### Darts Caller Module

Professional darts caller with TTS or custom audio packs.

**Features:**
- Score announcements after each turn
- Checkout calls ("You require...")
- Special calls: 180, bust, game shot, match shot
- Player change announcements
- Multiple output modes:
  - Browser TTS (Text-to-Speech)
  - Audio packs (pre-recorded MP3s)
  - Local playback (server-side audio)

**Voice Pack Generator:**
- Integrated ElevenLabs TTS support
- Generate complete voice packs with custom voices
- Configurable stability and clarity
- All required files generated automatically (scores, checkouts, special calls)

**Event Timing:**
- Uses synthetic events (`turn.finished`, `player.change`) for correct timing
- Score announced after turn, checkout announced after player change

## Technical Details

### Performance
- Minimal latency in event processing (<10ms)
- Efficient WebSocket communication
- Lazy-loading for module UIs

### Security
- Credentials are stored locally only
- No external data transfer except to Autodarts
- Local access to web interface recommended

### Compatibility
- Node.js 18+
- Modern browsers (Chrome, Firefox, Safari, Edge)
- WLED Version 0.13+

### API
- REST API for configuration and control
- WebSocket API for real-time events
- Module UI routing (`/module-ui/:moduleId/`)

See [API Documentation](api.md) for details.
